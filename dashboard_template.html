🔮 Predict a New Creative

Configure a hypothetical creative and get an instant performance estimate based on patterns learnt from all 1 080 existing creatives. The model uses K-Means cluster matching + PCA feature profiles.

How it works

The predictor uses patterns from the full 1 080-creative dataset to estimate performance of an untested configuration.

① Cluster matching
Finds which of the 8 K-Means clusters your creative profile resembles most, based on format, vertical, theme and tone.
② Feature adjustments
Applies boosts and penalties from the Random Forest feature importance for your specific KPI goal.
③ Similar creatives
Surfaces the top 3 existing creatives with the closest profile to benchmark your estimate.
⚠ Limitations
This is a heuristic estimate. Re-run ml_pipeline_sklearn.py locally to embed full PCA inference (sklearn model parameters) for higher accuracy.

⚡ Frequent Questions

What status should I act on first?
fatigued — pause or refresh now. top_performer — scale budget and create A/B variants. underperformer — reallocate budget. stable — monitor for early fatigue signals.
What is a good CTR / ROAS / CPA?
CTR: 0.8–2.5% typical, >2% strong.
ROAS: >1.0 = profitable, >2.0 = strong.
CPA: dataset range $1.7–$35, median ~$13. Lower is better.
IPM: 3–15 typical.
What drives performance most?
Ad format is the #1 driver across all KPI models. After that: novelty, vertical, motion, and has_gameplay (especially for CPA/IPM). Check the 💡 ML Insights → Feature Importance tab for your specific KPI.
How do I read the CTR decay chart?
Switch to Normalized view so all creatives start at 100%. Top performers keep ~33% of launch CTR; fatigued ads drop below ~16%. The benchmark lines make comparison fair regardless of how high the baseline CTR was.
How does the Portfolio Optimizer work?
Add your currently running creatives (Step 1). The optimizer ranks everything else by diversity score — how different each creative is from its closest portfolio neighbour, based on creative attributes and visual profile. Slide the strategy bar toward Diversity to explore new archetypes, or toward Performance to favour proven winners.
How do I use Predict Creative?
Set your target KPI, format, vertical, theme and tone, then click ⚡ Predict. Use ✨ AI Smart Fill first to get Gemini's suggestions on how to optimise the configuration for your KPI. The tool matches your spec to the nearest cluster and shows benchmark creatives.
What does perf_score mean?
A 0–1 composite of CTR, CVR, ROAS, and IPM (all min-max normalised within the dataset). CTR carries the most weight (r=0.82 correlation). >0.65 = top performer; <0.35 = underperformer. It lets you rank creatives consistently regardless of KPI type.
What are the clusters?
8 creative archetypes discovered by K-Means clustering on PCA-compressed features. Creatives in the same cluster share format, theme, tone and visual DNA. Click 🔵 Explain This Cluster in the Clusters tab for a plain-English description of each archetype.

📊 Performance Metrics

CTR — Click-Through Rate
Clicks ÷ Impressions. How often users tap the ad.
Typical 0.8–2.5% · Strong >2%
CVR — Conversion Rate
Conversions ÷ Clicks. Users who clicked and completed the goal action.
Typical 10–40%
CPA — Cost per Acquisition
Spend ÷ Conversions. Lower is better.
Dataset $1.7–$35 · Median ~$13
ROAS — Return on Ad Spend
Revenue ÷ Spend. >1.0 = profitable.
>2.0 = strong
IPM — Installs per Mille
Conversions per 1,000 impressions.
Typical 3–15
perf_score
Weighted 0–1 composite of CTR, CVR, ROAS, IPM.
>0.65 top performer · <0.35 underperformer
ctr_decay_pct
(last_7d_ctr − first_7d_ctr) / first_7d_ctr. How much CTR dropped from launch. Always negative. −0.67 = 67% drop.

🏷️ Status Labels

top_performer
perf_score >0.65 and CTR holds well over time. → Scale budget, create variants.
stable
Solid, consistent, no strong fatigue. → Monitor, consider iterating.
fatigued
Clear decay past fatigue_day. Audiences overexposed. → Pause or refresh. Do not scale.
underperformer
Weak KPI from launch, perf_score <0.35. → Reallocate budget. Rethink concept.

🎨 Creative Attributes — Quick Reference

ad_format — rewarded_video, interstitial, playable, banner, native. #1 performance driver.
novelty_score — visual originality vs. rest of dataset. High novelty fights banner blindness.
motion_score — animation intensity. Strong signal for IPM and CPA in video formats.
has_gameplay — shows actual gameplay footage. Top CVR predictor for CPA/IPM campaigns.
has_ugc_style — creator/selfie format. Boosts perceived authenticity, lifts CTR.
clutter_score — visual busyness. High clutter is negatively correlated with ROAS.
text_density — fraction of frame covered by text. 0 = image-dominant, 1 = text-heavy.
theme — gameplay, discount, testimonial, UGC, feature-focus, urgency, minimalist, etc.
tone — excited, playful, urgent, trustworthy, premium, calm, adventurous.
hook_type — opening technique: challenge, last-minute deal, story, before/after, cashback, etc.
has_discount_badge — sale/bonus badge visible. Creates urgency. Paired with has_price for purchase intent.
duration_sec — video length in seconds. Static = 0. Optimal length varies by format and vertical.

🤖 How the ML Works

Feature set (no data leakage)
24 features: 11 visual/structural scores + 8 categorical attributes + 5 binary flags. Outcome metrics are never used as inputs — only as targets.
Random Forest + SHAP
80 trees trained on all creatives. Feature importance = average error-reduction per split, normalised to 100%. SHAP values show each feature's exact contribution to a specific creative's predicted score.
XGBoost (KPI models)
Gradient-boosted trees trained separately for CPA, ROAS, IPM, CTR campaigns. Often more accurate than the global RF for a specific campaign goal.
PCA + K-Means clusters
PCA compresses features into 15 orthogonal components. K-Means finds 8 creative archetypes (C1–C8) based on feature-space proximity. Clusters are used by the Portfolio Optimizer and Predict Creative.
R² (cross-validation)
How well the model predicts unseen creatives. >0.5 is good for noisy creative data. Shown in ML Insights → CV Results.
Orthogonality score
How different a creative is from its closest portfolio neighbour, measured as a weighted blend of categorical attributes (format, vertical, theme, tone, KPI, OS — 65%) and PCA visual profile in 6D (35%). 100% = completely unlike anything you're running; 0% = a clone.

⚙️ Data Pipeline

Six source CSVs → two Python scripts → self-contained HTML dashboard.
ml_pipeline_sklearn.py
Joins CSVs → builds 24-feature matrix → PCA → K-Means → RF + XGBoost → SHAP → writes app_data.js + ml_results.json. Re-run after any data update.
build_dashboard.py
Injects app_data.js and ml_results.json into the template and adds your Gemini API key from .env. Outputs creative_copilot.html.
API key setup
Copy .env.example → .env, paste your Gemini key, run build_dashboard.py. The key is never committed to git.
